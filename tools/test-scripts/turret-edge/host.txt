# Scenario "turret-edge" (Remote Turret, R3): 3 copies. Runs after lobby-host.txt.
#   A. the host throws a turret at its own feet and uses it: it is picked up as the
#      Remote Turret (no Laptop Gun);
#   B. a turret near Zqclient, controlled, fired until its ammo runs out: firing
#      stops, control stays; Zqclient2 watches (its copy aims and fires too);
#   C. Zqclient2 kills the host while it controls the turret: control ends, the
#      turret explodes;
#   D. after respawning, a new turret near Zqclient2, controlled; Zqclient2 shoots
#      the turret to pieces: control ends ("the turret is destroyed").
